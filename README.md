# سایت ARYAN XD

یک سایت فارسی، واکنش‌گرا و مشکی/قرمز برای معرفی کانال آپارات.

## پیش‌نمایش روی کامپیوتر
فایل `index.html` را با مرورگر باز کن.

## انتشار در GitHub Pages
1. وارد GitHub شو و یک مخزن جدید بساز (مثلاً `aryan-xd-site`).
2. فایل‌های `index.html`، `style.css` و `script.js` را در ریشه‌ی مخزن آپلود کن.
3. در مخزن به **Settings → Pages** برو.
4. در بخش Build and deployment، گزینه‌ی **Deploy from a branch** را انتخاب کن.
5. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب و Save کن.
6. پس از چند دقیقه لینک سایت در همان صفحه نمایش داده می‌شود.

## تغییرات ساده
- تعداد دنبال‌کننده‌ها: در `script.js` مقدار `FOLLOWER_COUNT = 50` را عوض کن.
- لینک کانال: اگر آدرس کانالت عوض شد، لینک `https://www.aparat.com/shorts/user/Aryanxdark/shorts` را در `index.html` جایگزین کن.
- ویدیوها: کارت‌های بخش ویدیو فعلاً نمونه‌اند و به صفحه‌ی کانال وصل می‌شوند. برای هر کارت، لینک و عنوان ویدیو را با ویدیوی واقعی خودت جایگزین کن.
- لوگو: لوگوی AXD با CSS ساخته شده و نیاز به فایل تصویر ندارد. برای عکس واقعی خودت، یک تصویر با نام `profile.jpg` به مخزن اضافه کن و طراحی را مطابق تصویرت ویرایش کن.

نکته: عدد دنبال‌کننده در این نسخه ثابت و دستی است؛ این سایت بدون API رسمیِ قابل دسترس نمی‌تواند تعداد دنبال‌کننده‌ها را زنده از آپارات بخواند.
